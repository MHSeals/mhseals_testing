\title{The math behind the MHSeals boat tests}
\author{\texttt{mhseals\_testing}, \texttt{mhseals\_hardware}, \texttt{mhseals\_nav}}
\date{}

\begin{document}
\maketitle

\noindent This is a short course on every calculation the test suite and the
thruster chain make: how a command becomes four pulse widths, how the boat's
thrust is characterized, how the water is measured before the boat, how the
simulator's plant is built, and how a navigation run is scored. Each section
ends with the file that implements it, so you can read the math and the code
side by side. The prerequisites are basic linear algebra, ordinary differential
equations and multivariable calculus; every step that is not obvious from those
is written out. The notation is collected in one table in
Appendix~\ref{app:notation}.

\part{Thrust: allocation, characterization and speed}
\label{part:thrust}
\noindent Part~I follows a command from the effort the driver receives to the
motion it produces: the frames, the mixer that spreads an effort over four
thrusters, the ESC that turns thrust into a pulse width, the characterization
that measures the boat's response, the decoupling columns, and the velocity
controller that inverts the measured speed curves.
