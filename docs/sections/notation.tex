\section{Notation}
\label{app:notation}

One table for the whole document. The last column names the part where a symbol
is introduced (F: frames and Part~IV, I, II, III). A few letters are reused with
different meanings in different parts; where that happens the row says so, and
within one section a letter has one meaning only. Conventions that hold
everywhere: the body frame is FLU (Section~\ref{sec:frames}); the world frame is
ENU with the heading $\psi$ counter-clockwise from east; compass, GPS course and
the flight controller report $\psi_c = \pi/2 - \psi$, clockwise from north, and
the conditions estimator retains compass headings internally and rotates
velocities using their sine and cosine. Every $\pm$ is one standard deviation.
