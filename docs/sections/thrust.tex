\section{Speed curves and per-direction coupling}
\label{sec:thrust}

Steady speed is modelled separately for each axis and sign; signed correction
columns cancel measured cross responses.

\subsection{Speed curves}

A T200's thrust grows with $e|e|$, not with $e$. In normalized wrench units
$w = e|e|$, a hold on one axis at effort $e$ settles where thrust meets drag:
\[
  e|e| = d_1 v + d_2 v|v| ,\qquad d_1, d_2 \ge 0 .
\]
Each of the six directions (\code{surge+} \dots\ \code{yaw-}) has its own pair
$(d_1, d_2)$, fitted by least squares on the hold means at two or more effort
levels. A negative term (noise, or a single level) is dropped and the other is
refitted, so every fitted curve rises with speed. The controller inversion is given
in Section~\ref{sec:controller}.

Speeds are through the water: the world drift of Section~\ref{sec:char} is
turned into the body at each sample's heading and removed before the fit, and
only samples that command a single axis enter, so cross coupling never bends a
curve.

\subsection{One column per axis and sign}

The driver selects a correction column for each commanded axis by its sign:
\[
  \bm e'=C^+\max(\bm e,0)+C^-\min(\bm e,0),\qquad c^{\pm}_{jj}=1.
\]
For a single-axis command $\bm e=s a\bm e_j$, its corrected effort is
$s a\bm c_j^s$. The column maps effort to effort. The mixer composes these
single-axis contributions in thrust space as described in
Section~\ref{sec:mixer}. The driver's columns apply to manual effort commands
as well as controller outputs; the controller uses the per-axis speed curves.

\paragraph{Measuring a column.} The offline fitter fits an affine map from
measured cross-effort ratios to cross responses, and solves for its zero.
It stops when the normalized cross responses are within tolerance and retains
the best actually measured column. Operational characterization refuses to run
because runtime correction transitions and readback are unsupported; this
fitter is exercised with explicit offline fixtures.
